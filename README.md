## Proyecto
Pinterest Lite (simulación)

Fátima Paz

## Objetivo del proyecto
El objetivo de este proyecto es aplicar los conocimientos adquiridos durante el curso de Fundamentos y Prácticas de Testing, simulando el trabajo de un equipo de QA en un entorno de desarrollo ágil.

Se realizaron actividades de análisis, diseño de pruebas, ejecución de casos de prueba, documentación de defectos y pruebas de API.

## Alcance del testing
Se realizaron pruebas funcionales sobre distintas funcionalidades simuladas de la aplicación Pinterest Lite, incluyendo:

- Registro de usuario
- Inicio de sesión
- Búsqueda de contenido
- Visualización de pines
- Interacción básica con contenido

También se realizaron pruebas sobre endpoints de una API pública para validar respuestas, manejo de errores y estructura de datos.

## Resultados del testing
Se diseñaron y ejecutaron más de 30 casos de prueba funcionales.

Se documentaron defectos simulados para ejemplificar el proceso de reporte de bugs.

Se ejecutaron pruebas de API incluyendo:

- consultas GET
- creación de recursos (POST)
- actualización de recursos (PUT)
- validación de estructura JSON
- pruebas negativas

## Conclusión
Las pruebas realizadas permitieron validar el comportamiento esperado del sistema en distintos escenarios funcionales.

Las pruebas de API mostraron respuestas consistentes y manejo adecuado de errores en endpoints inexistentes.

En base a las pruebas realizadas, el sistema presenta un comportamiento estable dentro del alcance definido para este proyecto.
